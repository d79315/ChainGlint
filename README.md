# ChainGlint

ChainGlint is a distributed, real-time data processing engine that enables auto-scaling, cache-optimized data pipelines across a cluster.

ChainGlint is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/vishalrankhamb/ChainGlint.git`
2. `cd ChainGlint`
3. Install in editable mode: `pip install -e .`

## Configuration

ChainGlint is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
